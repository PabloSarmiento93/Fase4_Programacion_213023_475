
# Sistema Software FJ

## Sistema Integral de Gestión de Clientes, Servicios y Reservas

Proyecto desarrollado para el curso de Programación de la Universidad Nacional Abierta y a Distancia (UNAD).

## Descripción del proyecto

El sistema Software FJ permite gestionar clientes, registrar diferentes tipos de servicios y administrar reservas. Su desarrollo utiliza programación orientada a objetos en Python.

## Funcionalidades principales

- Registro y validación de clientes.
- Registro de diferentes tipos de servicios.
- Creación, confirmación y cancelación de reservas.
- Procesamiento de reservas y cálculo de costos.
- Aplicación de impuestos y descuentos.
- Manejo de excepciones y registro de eventos y errores.

## Estructura del proyecto

Los archivos principales se encuentran en la carpeta `src`:

- `main.py`: ejecuta el programa y las pruebas.
- `cliente.py`: contiene la clase Cliente.
- `entidad.py`: contiene la clase abstracta Entidad.
- `servicios.py`: contiene los servicios y sus clases especializadas.
- `reserva.py`: administra las reservas.
- `excepciones.py`: define las excepciones personalizadas.
- `logs.py`: registra eventos y errores del sistema.

## Tecnologías utilizadas

- Python 3.
- Programación orientada a objetos.
- Manejo de excepciones.
- Registro de eventos mediante archivos de log.

## Ejecución del programa

Desde una terminal, ingresa a la carpeta `src` y ejecuta:

```bash
python main.py
```
